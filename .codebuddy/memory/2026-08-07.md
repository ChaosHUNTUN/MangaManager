# 2026-08-07

## 阅读器新增快捷键 + 进度条

### 功能
1. **快捷键**: `Ctrl+←`(或Cmd+←) 快速定位第一页, `Ctrl+→`(或Cmd+→) 定位尾页
   - 位置: `ReaderLocal.jsx` 键盘处理 Ctrl 分支 (`goFirst`/`goLast` 已在依赖中)
2. **底部进度条**: 翻页模式(paginated)在工具栏显示可拖动的 range 进度条
   - `ReaderToolbar.jsx`: `.r-progress-row` 位于缩略图与工具行之间, `onChange → setCurrentPage`
   - `reader.css`: `.r-progress-slider`(accent 色滑块+自绘 thumb) / `.r-progress-label`(页码)
   - 连续模式不显示(ContinuousView 纯滚动定位, 不响应 currentPage)

### 关键点
- `onPointerDown={e => e.stopPropagation()}` 防止拖动进度条穿透触发画布点击
- 进度条拖动 → currentPage 变化 → 自动触发 2s 防抖进度保存
