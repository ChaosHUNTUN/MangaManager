## 控制台卡死修复 (2026-07-28 晚间)
- **根因**: `Dispatche.Invoke` 在进程 `OutputDataReceived` 回调中同步阻塞 → ThreadPool 线程排队等 UI → 子进程管道缓冲区(4KB)满 → 子进程 `WriteLine`阻塞 → 父子互相等待死锁
- **修复1**: `Dispatcher.Invoke` → `Dispatcher.BeginInvoke`（StartProcess 的 OutputDataReceived/ErrorDataReceived/Exited 三个回调）
- **修复2**: `Log()` 方法 `ScrollToEnd()` 节流（每 200ms 一次）+ 行数上限 2000 行防止 TextBox 无限膨胀
- **修复3**: Timer Tick 防重入（`_refreshingStatus`/`_refreshingTasks` 标志），阻止 HTTP 超时导致并发请求堆积
- **新增字段**: `_refreshingStatus`, `_refreshingTasks`, `_lastScrollTime`, `MaxLogLines=2000`
