## 2026-07-29 — 阅读器重构

### 重构原因
原 ReaderShowcase.jsx ~750行单文件，四维状态交叉缠绕、百分比高度链条失效导致显示BUG、gesture/keyboard处理分散。

### 架构重写
拆分为 7 个文件 + 1 个 CSS：

```
src/visual-test/
├── reader/
│   ├── useReaderEngine.js    ← 扁平状态机 + getImageLayout(零扭曲)
│   ├── gestureUtils.js       ← swipe检测 + grab scroll
│   ├── PageCanvas.jsx        ← LazyImage + PageCanvas
│   ├── PaginatedView.jsx     ← 翻页模式 (swipe + 点击区)
│   ├── ContinuousView.jsx    ← 滚动模式 (grab scroll)
│   ├── ThumbnailStrip.jsx    ← 缩略图条
│   ├── ReaderToolbar.jsx     ← HUD + 底部工具栏
│   └── reader.css            ← 阅读器样式
└── pages/ReaderShowcase.jsx  ← 入口 (110行)
```

### 核心设计原则
- **零扭曲**: 所有图片 width/height 使用同一个 scale，禁止 aspect-ratio / object-fit:fill
- **扁平状态**: 9 个独立 state，无交叉派生
- **方向感知**: 键盘/手势随 direction 变化 (horizontal ↔ vertical)
- **Flow 语义**: paginated→翻页幻灯片, continuous→自动滚动
- **编译验证**: 8/8 模块编译通过 (200 OK)
