## Git 连接排查（实为 PowerShell stderr 误报）
- **现象**: 用户报告无法 git pull/push，出现红色 "RemoteException"
- **根因**: git 把进度信息写入 stderr，PowerShell 7 将其渲染为红色错误对象。实际 `git fetch`/`git pull` 均成功
- **解决**: 用 `git pull 2>$null` 忽略 stderr

## 删除下载任务"无法执行"修复（多层问题叠加，曾两次应用）
- **根因1（前端 DownloadMonitor.jsx）**: 删除成功后任务不从列表移除；SSE `removed` 事件把任务变"已移除"灰条仍残留
- **根因2（后端 DownloadManager.RemoveTask）**: 依赖内存字典 `_tasks`，API 重启后历史已完成任务不在内存 → `TryRemove` false → 400"任务不存在"
- **根因3（控制台）**: `BtnRemoveTask_Click` 不检查响应状态，失败也显示成功，下次 5s 轮询任务"复活"
- **交互限制**: 前端 pending 无删除按钮、控制台 downloading 无删除按钮
- **修复**: 后端以删 DB 记录为准（保留远程 `_taskCts` 取消令牌机制）；前端 SSE removed 过滤 + onRemove 本地移除 + 所有状态可删；控制台检查响应 + 删除后立即 RefreshDownloadTasks()

## 阅读模式接口报错修复（下载目录配置丢失）
- **现象**: `GET /api/local/gallery/4031777/pages` 返回 `data:[]` 空数组，阅读模式打不开
- **根因**: `appsettings.json` 的 `Ehentai:DownloadDir` 为空 → API 下载目录默认 `bin\Debug\net9.0\downloads`（不存在）→ `LocalGalleryService.FindLocalDir` 用 `Directory.GetDirectories(BaseDir, "{gid}-*")` 找不到画廊目录 → 返回空列表
- **画廊真实位置**: `G:\学习资料\本子\`（2491 个目录，与 DB local_gallery 2466 条对应），此目录存在但未被配置
- **修复**: `appsettings.json` 设置 `"DownloadDir": "G:\\学习资料\\本子"`
- **坑**: 用 `Start-Process` 启动 exe 若不指定 `-WorkingDirectory`，ASP.NET 从工作目录加载 appsettings.json，配置读不到（仍返回空）→ 必须指定工作目录为 bin\Debug\net9.0
- **注意**: 个人路径入库 git，用户介意硬编码个人路径，后续可改环境变量 `Ehentai__DownloadDir` 注入
- 已验证: 页面接口返回 31 页，图片接口 200 image/webp 16MB
