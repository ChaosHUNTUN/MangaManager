# 2026-07-21

## ExHentai 下载失败 Bug 修复

**问题**: 18个里站(exhentai)作品下载全部失败

**根因**: `EhentaiService.GetPagesAsync` → `GetGalleryPageHtmlAsync` 硬编码使用 `HOST_E` (e-hentai.org) 获取画廊HTML页面。里站专属作品在表站返回 "This gallery is unavailable"，导致解析出 0 个图片页面。

**修复内容**:
- `EhentaiService.cs`: `GetPagesAsync`、`GetGalleryPageHtmlAsync`、`FetchImageFromPageAsync` 增加 `bool isExhentai` 参数
- `DownloadManager.cs`: `DownloadTaskAsync` 将 `detail.IsExhentai` 传递给上述方法
- `GetGalleryPageHtmlAsync` 增加自动兜底：表站返回 "unavailable" 时自动重试里站

## 下载最后几页失败 Bug 修复

**问题**: 5个作品 99%+ 页成功下载，但最后 1-3 页失败导致整个任务标记为 failed，且 ErrorMsg 为空

**根因**:
1. `FetchImageFromPageAsync` 在 /s/ 页面匹配不到图片时静默返回 `(null,"")` 不抛异常，导致重试后无错误信息
2. `ExecuteTaskAsync` 中 `FailedPages > 0` 即标记 failed，阈值过严

**修复内容**:
- `EhentaiService.cs` - `FetchImageFromPageAsync`: HTTP 非 200→抛 HttpRequestException；匹配不到图片→抛 InvalidOperationException 并附带 HTML 片段
- `DownloadManager.cs` - `ExecuteTaskAsync`: 成功率 >= 95% 视为 completed；失败时设置带成功率/页码的 ErrorMsg
- `DownloadTaskAsync`: 单页失败时记录最后错误到 task.ErrorMsg

## 局域网访问图片加载失败修复（2026-07-22）

**问题**: 局域网其他设备访问前端时所有图片/API 请求失败

**根因**: `API_BASE` 只将 `localhost`/`127.0.0.1` 识别为开发模式并指向 5000 端口；局域网 IP(192.168.x.x) 被当作生产模式返回空字符串，导致请求打到 Vite dev server(5173)而非 API(5000)

**修复**:
- `vite.config.js`: 添加 proxy，将 `/api` 转发到 `http://localhost:5000`
- `api.js`: `API_BASE` 简化为 `''`（始终同源，由 Vite proxy 处理开发模式路由）
