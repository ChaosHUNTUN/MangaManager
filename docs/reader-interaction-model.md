# 阅读器交互模型设计

> 版本：1.0（2026-08-26）
> 范围：`ReaderLocal` 统一阅读器（翻页/滚动、阅读方向、自动阅读、作品间导航）的操作逻辑与输入映射。
> 目标：让"规则只有一句话"，用户不需要记忆每个模式的键位表。

## 1. 设计原则

1. **模式与方向正交**：阅读模式（离散页 / 连续滚动）和阅读方向（纵 / 横 / RTL）是两个独立维度，任意组合都有明确行为。
2. **主轴键服务主操作**：阅读轴上的键盘/手势/热区只做"阅读"（翻页或滚动），绝不兼任其他功能。
3. **交叉轴键服务作品导航**：与阅读轴垂直的那根轴，统一承担"上一部/下一部"。
4. **键盘语义固定、触摸语义随方向**：`→`=前进、`←`=后退在任何模式下都不反转；点击热区与滑动方向随阅读方向调整。
5. **冲突时以主操作为准**：手动滚动打断自动阅读、放大平移优先于交叉轴导航等。

## 2. 正交状态模型

两个独立维度，UI 上暴露为"方向"预设：

| 维度 | 取值 | 决定内容 |
|---|---|---|
| 模式 `mode` | `paged` / `scroll` | "页"的离散/连续语义、自动阅读实现、进度粒度 |
| 方向 `direction` | `vertical` / `horizontal-ltr` / `horizontal-rtl` | 主轴、前进方向、翻页动画、点击热区、手势方向 |

方向内部 = `axis`（横/纵）× `order`（正序/反序），便于未来扩展（如纵向倒序）。

### 前进方向定义

| 方向 | 前进 = |
|---|---|
| vertical | 向下（翻页模式为向下整页翻） |
| horizontal-ltr | 向右 |
| horizontal-rtl | 向左（布局反向，初始位置在最右） |

## 3. 输入映射矩阵

### 键盘（桌面）

规则：**主轴键 = 阅读主操作；交叉轴键 = 上一部/下一部；PgUp/PgDn = 全模式作品导航别名；空格 = 自动阅读**。

| 键 | paged/scroll · 纵向 | paged/scroll · 横向 |
|---|---|---|
| 主轴键（纵向 `↑↓` / 横向 `←→`） | paged：翻页；scroll：滚动 ±300px | paged：翻页；scroll：滚动 ±300px |
| 交叉轴键（纵向 `←→` / 横向 `↑↓`） | 上一部 / 下一部 | 上一部 / 下一部 |
| `PgUp` / `PgDn` | 上一部 / 下一部 | 上一部 / 下一部 |
| `Home` / `End` | 第一页 / 最后一页 | 第一页 / 最后一页 |
| `Ctrl+←/→` | 第一页 / 最后一页 | 第一页 / 最后一页 |
| `空格` | 自动阅读 播放/暂停 | 自动阅读 播放/暂停 |
| `[` / `]` | 自动阅读时 减慢/加快（间隔 1–60s / 速度 20–1600px/s） | 同左 |
| `F` | 切换 翻页/滚动 | 切换 翻页/滚动 |
| `D` | 切换 纵向/横向 | 切换 纵向/横向 |
| `0` / `Ctrl+滚轮` / `Ctrl+±` | 缩放 | 缩放 |
| `Esc` | 返回书架 | 返回书架 |
| `?` / `H` | 快捷键面板 | 快捷键面板 |

作品导航语义固定：`←`/`↑` = 上一部（列表靠前），`→`/`↓` = 下一部（列表靠后），**按书架列表顺序，不随 RTL 反转**。

### 触摸 / 手势

与键盘同一规则：**主轴滑动 = 阅读主操作，交叉轴滑动 = 作品导航**。

| 模式 | 主轴滑动 | 交叉轴滑动 |
|---|---|---|
| paged · 纵向 | 上滑=下一页、下滑=上一页 | 左滑=下一部、右滑=上一部 |
| paged · 横向（LTR） | 左滑=下一页、右滑=上一页 | 上滑=下一部、下滑=上一部 |
| paged · 横向（RTL） | 左滑=下一页、右滑=上一页（同 LTR，符合实体漫画翻页手感） | 上滑=下一部、下滑=上一部 |
| scroll · 纵向 | 上下滚动（拖拽/惯性） | 边缘手势或按钮（避免误触） |
| scroll · 横向 | 左右滚动 | 边缘手势或按钮 |

> scroll 模式下交叉轴滑动默认不启用，避免滚动时误触；用工具栏按钮或 PgUp/PgDn（外接键盘）。

**横向 RTL 键盘**（工具栏 `左→右 / 右→左` 开关，仅横向模式显示）：paged 下 `←`=下一页、`→`=上一页；scroll 下 `←`=向前滚动、`→`=向后滚动（`row-reverse` 布局第 0 页在最右，scrollLeft 增大=向后读，故键位语义随 RTL 翻转，与分页保持一致）。

### 点击热区（paged 模式，UI 隐藏时）

| 方向 | 上一页热区 | 下一页热区 |
|---|---|---|
| 纵向 | 顶部 30% | 底部 30% |
| 横向 LTR | 左 30% | 右 30% |
| 横向 RTL | 右 30% | 左 30% |

中间区域点击 = 切换 UI 显隐。

## 4. 放大平移的让位规则

放大后（zoom > 1 且内容超出视口），需要平移画面时，**交叉轴键优先平移，作品导航退位**到 PgUp/PgDn 与工具栏按钮：

- scroll · 纵向 + 放大：`←→` 平移横向溢出（如有），不再切作品
- scroll · 横向 + 放大：`↑↓` 平移纵向溢出（如有），不再切作品

判断依据：当前轴是否存在可滚动溢出。

## 5. 自动阅读契约

统一入口 `toggleAutoRead()`（空格），按模式选择实现，共享行为契约：

| 模式 | 实现 | 参数（滑块连续调节） |
|---|---|---|
| paged | 定时翻页 | 间隔 1–60s（步进 1s，默认 5s） |
| scroll | 匀速滚动 | 速度 20–1600 px/s（步进 10，默认 120） |

### 冲突管理

| 用户操作 | scroll | paged |
|---|---|---|
| 手动滚动 / 拖拽 / 滚轮 | **自动阅读立即暂停** | 不适用 |
| 手动翻页（按键/点击/手势） | 不适用 | 继续（翻页间隔重置） |
| 到达末尾 | 停止并提示（可选循环） | 同左 |

指示器常驻显示状态（`▶ 5s/页` 或 `▶ 中速`）+ 整体进度；图片加载失败时跳过或停止并提示。

## 6. 进度模型

| 模式 | 存储 | 恢复 |
|---|---|---|
| paged | `pageIndex` | 直接定位 |
| scroll | `pageIndex + 页内偏移(0~100%)` | 定位到帧，再滚到偏移位置 |

模式切换锚点：paged ↔ scroll 切换时用当前页作为锚点，切换后停留在同一页附近，不回到开头。

**实现（2026-09-01）**：`local_reading_progress` 新增 `ScrollOffset REAL NULL`（迁移 `AddScrollOffsetToReadingProgress`）；滚动模式保存 `pageIndex + 0~1 偏移`（当前帧内中线相对位置），分页模式偏移恒为 null（避免滚动残留污染分页进度）；恢复时先定位到帧，等帧有真实尺寸后滚到「帧起点 + 偏移 × 帧尺寸」（`scrollRestore` 意图 + ContinuousView 应用后清除，图片懒加载尺寸未就绪时随 dimsMap 重试）；同页滚动只更新偏移并走同一 2s 防抖保存。滚动跟踪回调 `onPageChange(page, offset)` / `onOffsetChange(offset)` 驱动。

## 7. 作品间导航

- **入口**：工具栏"上一部/下一部"按钮 + 交叉轴键 + PgUp/PgDn（别名）
- **上下文**：进入阅读器时保存书架筛选/排序上下文（`reader-local-full-gids` / `reader-local-context`，已实现）
- **边界反馈**：第一部/最后一部时按钮置灰；键盘触发边界时显示轻提示（"已是第一部"），不静默
- **切换时序**：保存当前进度 → 路由到下一部 → 恢复其进度
- **预加载（2026-09-01 已实现）**：读到每部最后 5%（至少 3 页）时预取下一部 pages 列表，会话内缓存（`pagesCacheRef`），切换秒开；已看过的作品返回也走缓存
- **返回书架**：保存进度后回到进入前的筛选/排序位置（`reader-local-return-url`，已实现）
